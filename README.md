# 知构 · 大学教师智能备课工作台

面向大学教师的本地备课工具：从课件、文档、大纲或单个知识点出发，组织教学单元、知识分析、教学资源与课堂时间轴。动效是其中的一个模块，不是整个平台的唯一入口。

- [项目展示](https://xiaoxiaoei.github.io/zhigou-demo/)
- [部署与教育优惠说明](DEPLOYMENT.md)
- [公开版安全边界](SECURITY.md)

## 功能

- 课程大纲建立空白教学单元，后续补充材料和知识点。
- PPT/PPTX、Word、PDF 输入；支持课件/PDF 选页预览与分析。
- 知识点与材料证据、课堂活动、诊断题组织。
- SVG/HTML 动效讲解方案、草稿、版本、逐阶段预览与修改。
- 课堂时间轴、资源编辑、课堂诊断记录、课堂包导出。
- 模型与 API 配置；支持兼容 OpenAI 的接口及本地 Ollama。

模型输出并不等于正确的教学内容，学科原理、材料引用和课堂可用性必须由教师核对。质量检查不替代人工审查。

## 本地启动

建议使用 Node.js 22 LTS 或更新的受支持版本。

```sh
git clone https://github.com/xiaoxiaoei/zhigou-demo.git
cd zhigou-demo
corepack enable
pnpm install --frozen-lockfile
cp .env.example .env
pnpm start
```

打开 http://localhost:3000/。在“模型与 API 设置”填写自己的服务地址、模型与密钥。不要将密钥写入前端或提交 Git。

如果不使用 Corepack，可自行安装 pnpm 后运行上述命令。模型名称和可用性以供应商账户控制台为准；示例配置不会自动调用任何付费模型。

PPT/PPTX 页面预览及旧版 PPT/DOC 转换需要安装 LibreOffice。PDF/DOCX 文本解析不依赖 Office。扫描页识别有平台依赖，macOS 原生识别脚本不等于 Linux 上具备相同功能。

文件上限默认 50 MB，选页之后才进行正式分析。图片大小不等于 Token 数，正文长度、模型和生成次数共同影响费用。

## 测试

```sh
pnpm test
```

测试使用模拟模型，不会消耗你的模型额度。两项真实课件集成测试在未设置 `TEST_PPTX_PATH` / `TEST_PROCESS_PPTX_PATH` 时跳过；不分发真实课程材料。个人浏览器操作脚本、截图和本地试运行记录不包含在公开版中。

## 两种网址不是一回事

GitHub Pages 上是免费项目说明页，**不是完整在线备课服务**。完整功能依赖本地 Node.js 服务、模型接口和文档转换组件；不能直接双击 public/index.html 或放到 Pages 就获得后端功能。

## 数据与隐私

本仓库是经过筛选的源码公开快照，不包含真实课件、学生资料、浏览器工作区、生成任务记录、实际 API 密钥和本机路径。源代码中的演示场景与测试样例为开发示例，不作为真实课堂成效证据。

本地课程内容主要保存在浏览器工作区，后端任务记录默认保留七天。浏览器清理数据、换设备或云主机重启不等于自动备份；使用前请导出重要成果。
